# Security

Ce dépôt contient des règles de détection et des playbooks à but éducatif et de lab.

## Usage responsable
- À utiliser uniquement dans des environnements **autorisés** (lab, tests de votre organisation).
- Ne pas utiliser pour des actions malveillantes.

## Signaler une vulnérabilité
- Si un module contient une erreur dangereuse ou un faux positif massif :
  ouvrez une issue privée (Security → Report a vulnerability) ou un PR de correction.
